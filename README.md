# Unravel Network

**UNRAVEL — Beyond Boundaries**

中文理念：**解开束缚，连接无界**

Unravel Network 是 UNRAVEL 母品牌下的网络服务与基础设施项目。这个仓库用于个人学习、测试，并逐步搭建一个可扩展的网络代理平台；未来可以加入其他网络代理服务。项目当前从网络基础和本地实验开始，暂不包含商业化功能。

> UNRAVEL 是母品牌，不等同于网络代理服务。Unravel Network 是母品牌旗下的一个具体项目。

## 学习与实验目标

- 理解网络协议和代理服务的工作方式。
- 从可观察、可验证的本地实验开始，逐步构建代理平台能力。
- 记录配置、实验步骤、结果和问题，形成自己的学习资料。
- 在需要时探索 Linux、云服务器、私人订阅、多节点和平台架构。

课程和实验记录用于项目所有者自己的学习。若仓库保持公开，请在提交前检查记录中没有个人信息、服务器地址、访问令牌或其他敏感数据。

## 当前架构

当前仓库是文档与实验骨架，尚无运行中的代理服务或应用代码。

```text
docs/
  architecture/  架构草图与技术说明
  courses/       课程路线与学习文章
  decisions/     重要技术决策记录
  experiments/   实验过程与结果
examples/        可公开分享的示例配置
scripts/         可复用的本地辅助脚本
src/             后续平台实现
```

从本地学习与实验开始；只有在需求清晰、风险和安全边界明确后，才扩展到服务器或多节点环境。

## 学习路线

1. **网络基础与协议**：网络分层、IP 与子网、DNS、TCP/UDP、HTTP/HTTPS、代理原理。
2. **本地代理实现**：代理类型、请求转发、配置管理、日志与基本测试。
3. **Linux 与云服务器部署**：Linux 网络工具、服务进程、反向代理、防火墙与部署验证。
4. **私人订阅系统**：订阅数据模型、客户端配置分发、访问控制与隐私保护。
5. **多节点与故障切换**：节点健康检查、路由选择、故障检测与恢复演练。
6. **网络平台架构探索**：服务边界、控制面与数据面、可观测性、扩展和运维权衡。

每个课程单元按“原理、实践、验证、常见错误、学习笔记”组织。课程入口见 [`docs/courses/README.md`](docs/courses/README.md)。

## 本地开发

当前没有应用运行时或依赖安装步骤。可直接阅读课程并在本机完成练习。克隆仓库后：

```powershell
git clone <仓库地址>
Set-Location unravel-network
Get-ChildItem -Force
```

课程中的命令以 PowerShell 或常见跨平台网络工具为例；执行前先阅读命令作用，只对自己拥有或获准使用的系统进行测试。新增代码后，再在对应目录补充明确的运行与验证说明。

## 安全原则

- 仅在自有设备、服务器或明确获准的环境中进行网络测试。
- 不提交密码、私钥、访问令牌、真实私人订阅链接、个人身份信息或生产凭据。
- 示例使用虚构域名、保留地址或明确标注的占位值；分享实验记录前检查日志与命令输出。
- 远程服务器实验应先说明暴露端口、访问控制、数据流向和清理方法。
- 发现凭据意外进入 Git 历史时，应立即撤销或轮换凭据，并按项目流程处理历史清理。
