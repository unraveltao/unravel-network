# 网络课程路线

课程服务于 Unravel Network 项目所有者的个人学习和实验。按阶段逐步推进；每个单元都遵循统一的学习记录结构：

1. **原理**：要理解的概念、数据流或协议行为。
2. **实践**：在本地或获准环境中完成的小实验。
3. **验证**：可观察的预期结果及检查方法。
4. **常见错误**：容易混淆的概念、配置问题和排查线索。
5. **学习笔记**：记录自己的解释、疑问和结论。

第一阶段文章已展开，见 [`stage-1-network-foundations.md`](stage-1-network-foundations.md)。后续阶段先保留单元大纲，学习时再逐篇补全。

## 六阶段路线

| 阶段 | 目标 | 课程单元 |
|---|---|---|
| 1. 网络基础与协议 | 建立理解代理数据流所需的网络知识 | 网络分层与 TCP/IP；IP 地址与子网；DNS；TCP 与 UDP；HTTP 与 HTTPS；代理工作原理 |
| 2. 本地代理实现 | 在本机观察并实现基本请求转发 | 正向代理与反向代理；监听地址与端口；请求转发；超时与错误处理；日志与配置；本地集成验证 |
| 3. Linux 与云服务器部署 | 理解服务进程和远程网络边界 | Linux 网络命令；进程与服务管理；防火墙与端口；TLS 与反向代理；部署与回滚；远程连通性验证 |
| 4. 私人订阅系统 | 安全管理个人配置与客户端分发 | 订阅数据模型；身份与访问控制；配置生成；更新与撤销；隐私与日志；客户端验证 |
| 5. 多节点与故障切换 | 管理多个代理节点并验证恢复能力 | 节点登记；健康检查；延迟与可用性；路由选择；故障检测与切换；恢复演练 |
| 6. 网络平台架构探索 | 形成可维护、可扩展的平台设计 | 控制面与数据面；服务边界；配置与状态；可观测性；容量与可靠性；安全和运维权衡 |

## 后续阶段单元记录模板

复制以下结构到单元文章中，并在实际学习后补充验证结果与笔记：

### 原理
说明概念、适用范围和关键数据流。

### 实践
记录环境、命令或配置；敏感值统一使用占位符。

### 验证
写明预期结果、实际观察和可复现的检查方式。

### 常见错误
列出症状、可能原因和排查方法。

### 学习笔记
记录自己的理解、未解决问题和下一步。
